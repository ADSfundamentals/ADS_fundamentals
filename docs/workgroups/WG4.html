Assumptions and diagnostics

Check these on your final model, using the code and plots from this week’s lab:

Assumptions

  1. Linear in the parameters
  2. Full rank: no predictor is a linear combination of others
  3. Exogenous predictors
  4. Constant error variance
  5. Uncorrelated errors: serial dependence, clustering
  6. Normally distributed errors

Influential observations

  • Outliers
  • High leverage
  • Influence
