Data processing: what to check

Classes

  • Are character classes set correctly?
  • Survey data from SPSS often come as labelled variables
  • Adjust with as_factor() or as.numeric()

Missing values

  • Are missing values recognized as NA?
  • Surveys often use codes such as -9, 77, 88, 99 for “don’t know” or “refused”
  • Check the codebook!

Scale scores

  • Do you need to calculate sum scores or mean scores of multiple items?
  • Are some items reverse coded?

Linking & selecting

  • Do you need to link multiple separate datasets (e.g. students and schools)?
  • Select only the variables (and cases) you need

Data processing: examples in R

library(tidyverse)
library(haven)

# Import and inspect
dat <- read_sav("data/survey.sav")
glimpse(dat)
summary(dat)

# Fix classes
dat <- dat |>
  mutate(gender = as_factor(gender),
         age    = as.numeric(age))

Data processing: examples in R

# Recode missing value codes to NA
dat <- dat |>
  mutate(across(c(item1, item2, item3), ~ na_if(.x, 99)))

# Reverse code an item (scale 1-5)
dat <- dat |>
  mutate(item3_r = 6 - item3)

# Compute a mean score
dat <- dat |>
  mutate(wellbeing = rowMeans(pick(item1, item2, item3_r),
                              na.rm = TRUE))

# Link two datasets on a shared ID
full <- left_join(students, schools, by = "school_id")
