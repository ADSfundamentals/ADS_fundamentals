2. Hand-in assignment

With this hand-in assignment, you demonstrate that you can set up a project as you learned during the lecture, import external data, know how to work with pipes, calculate some descriptive statistics, and know how to make a reproducible report using Quarto.

Data: penguins.csv (click to download) contains measurements of 344 penguins from the Palmer Archipelago in Antarctica. Note that the file uses semicolons to separate columns and commas as decimal marks.

What to hand in
  • Hand in only your rendered .html file. Do not hand in your .qmd file, the data or a zip of your project.
  • Name your file lab1_firstname_lastname_studentnumber.html, for example lab1_jane_doe_1234567.html.
  • Use embed-resources: true in your header so that your figure is stored inside the .html file.

Set up your project

Exercise 1

Set up an R project with the same folder structure as the “good” example from the lecture (see the Project Organization Demo):

  1. In RStudio, create a new project called lab1 (File > New Project > New Directory > New Project).
  2. Inside the project folder, create the folders code, data, figures and output.
  3. Download penguins.csv and save it in the data folder.
  4. Create a new Quarto document (File > New File > Quarto Document) and save it in the code folder as lab1_firstname_lastname_studentnumber.qmd.
---
title: "lab1_firstname_lastname_studentnumber"
author: "Firstname Lastname"
format:
  html:
    embed-resources: true
---

Your project should now look like this:

lab1/
├── lab1.Rproj
├── code/
│   └── lab1_firstname_lastname_studentnumber.qmd
├── data/
│   └── penguins.csv
├── figures/
└── output/

Import the data

Exercise 2

Add a code chunk that loads the dplyr package. Then, just like in the example from the lecture, define a variable for each folder in your project:

dataDir <- "data"
outDir  <- "output"

Read penguins.csv into an object called penguins with read.csv2() and here::here(dataDir, "penguins.csv").

Descriptive statistics with pipes

Exercise 3

Convert species into a factor with the levels "Adelie", "Chinstrap" and "Gentoo" (in that order). Then use table() to count the penguins of each species.

Exercise 4

Calculate the mean body mass (body_mass_g) of all penguins, rounded to 1 decimal. Write this as one pipeline using the base R pipe |>. Remember that body_mass_g contains missing values.

Exercise 5

Use group_by() and summarise() in a pipeline to calculate the mean body mass per species, rounded to 1 decimal. Which species is the heaviest on average?

Reproducible reporting

Exercise 6

Write one sentence in your document (as normal text, not in a code chunk) that reports the mean body mass from Exercise 4. Do not type the number yourself: use inline code so that the number is calculated when you render the document.

Hint: inline code looks like this: `r 1 + 1`

Exercise 7

Make a boxplot of body mass per species with base R’s boxplot() function. Add a caption to the figure with the chunk option #| fig-cap:, and give the axes clear labels.

Also save the boxplot as an image in your figures folder. png() opens an image file, the plot is drawn into that file, and dev.off() closes it:

png(here::here(figDir, "boxplot_mass.png"))
boxplot(body_mass_g ~ species, data = penguins,
        xlab = "Species", ylab = "Body mass (g)")
dev.off()
